# 📋 CopyFy++

Un portapapeles inteligente y moderno para tu escritorio, desarrollado con **Electron + React + Vite + TypeScript**. Guarda automáticamente el contenido copiado (texto o imágenes), permite buscar, traducir al inglés y copiar con un solo clic. Ideal para creadores de contenido, desarrolladores y usuarios multitarea.

![CopyFy++ Preview](./preview.png)

---

## 🚀 Características

- ✅ **Historial del portapapeles** (texto e imágenes)
- 🔍 **Buscador integrado** para filtrar contenido
- 🌐 **Traducción instantánea al inglés**
- 🌙 **Modo oscuro automático**
- 🎨 Interfaz minimalista, ligera y personalizable
- 🖱️ Arrastrable, sin bordes (ventana sin marco)
- ⚡ Basado en tecnologías modernas (Vite, React, Electron)
- 🧠 Soporte para código con resaltado (highlight.js)
